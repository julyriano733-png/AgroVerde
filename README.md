# *AgroVerde*

![Logo Agro verde](./Agro%20verde.png "Agro Verde")

Sistema de gestión de terrenos, cultivos, sanidad vegetal e inventario agrícola para el Centro Agropecuario del SENA.

Agro Verde es una aplicación móvil orientada a digitalizar y optimizar el control de terrenos, el seguimiento fenológico de siembras, la gestión de insumos agrícolas y la trazabilidad del tiempo de trabajo en campo.

# *Características Principales*

    - Gestión de Terrenos y Parcelas: Control y registro detallado de espacios de siembra.

    - Seguimiento Fenológico: Monitoreo del ciclo de vida y etapas de desarrollo de los cultivos.

    - Inventario de Insumos: Control de stock, agroquímicos y herramientas para evitar discrepancias.

    - Control de Tiempos: Registro de labores agrícolas y horas de práctica de los aprendices.

    - Modalidades de Despliegue: Preparado para funcionar en la nube (SaaS) o en servidores locales (On-Premise).
